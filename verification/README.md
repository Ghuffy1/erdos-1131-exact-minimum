# Verification evidence

`VERIFIED_COMMIT` identifies the exact proof revision checked. Later commits add evidence and submission preparation. They preserve the selected proof source.

- [Full verification report](report.md)
- [Machine-readable results](results.json)
- [Environment and dependency pins](environment.json)

Set the portable manifest's example checkout root to your actual absolute path before running the pinned prize helper. Local directory prefixes in shared logs are normalized to `/work`. The selected proof, observed results, timestamps, and log contents are otherwise preserved.
